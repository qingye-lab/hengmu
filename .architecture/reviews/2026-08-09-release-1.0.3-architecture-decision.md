# Hengmu 1.0.3 release-integrity decision

Status: accepted on 2026-08-09 by the `architecture-owner` role.

Hengmu will keep its local-first plugin architecture and ship the smallest
compatible release-integrity correction. Version 1.0.3 rejects unsafe raw ZIP
entry names before platform normalization, makes tag publication depend on the
complete quality matrix, preserves unique per-run governance inputs, and binds
host and model claims to dated evidence.

Deferring the changes was rejected because it leaves the demonstrated Windows
archive invariant and publication race unresolved. Building lifecycle adapters
for every named host was rejected because only the Codex route has current host
evidence and no other host has demonstrated an adapter requirement.

The decision is bound to the 1.0.3 skeptical follow-up V2 Review. That Review reports
zero unresolved Findings, complete coverage of 31 rules and six critical flows,
and a source-matched deterministic run at `fba6b93` with 161 passing tests.
