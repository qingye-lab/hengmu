# Hengmu 1.0.4 release-provenance decision

Status: accepted on 2026-08-10 by the `architecture-owner` role.

Hengmu will publish version 1.0.4 as the smallest compatible provenance patch.
The release preserves every public Skill, artifact schema, and runtime package
boundary while exercising the verified immutable `actions/attest` 4.2.2 pin for
release provenance and both package SBOM attestations.

Deferring publication was rejected because it leaves the tag-only release path
unproved and does not complete the explicitly authorized release. Replacing the
version 1.0.3 tag or assets was rejected because it would break immutable release
identity and invalidate existing checksums, SBOMs, attestations, and caches.

The decision is bound to the anchored independent V2 Review, which reports zero
findings, complete coverage of 31 rules and six critical flows, and a
source-matched deterministic Evidence Provider run with 161 passing tests.
Two independent package builds were byte-identical and a real Codex CLI 0.147.0
macOS installation routed the packaged plugin successfully. The remaining
release-specific evidence must come from the hosted branch and tag workflows,
downloaded checksum verification, and published attestation verification.
