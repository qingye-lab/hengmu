# Version 1.0.3 model behavior evidence

Observed on 2026-08-09 with `codex-cli 0.147.0`.

## Method

- Ten outcome-neutral, read-only fixtures.
- Two identified models: `gpt-5.6-sol` and `gpt-5.6-terra`.
- Three fresh, ephemeral Codex processes per model and case.
- Sixty accepted trials in total.
- Full-context treatment from the checked-in ablation manifest.
- Ground Truth was excluded from prompts, fixture names, and fixture content.
- Finding evidence was resolved from fixture-relative paths, line ranges, and
  verbatim excerpts; the adapter allowed at most one evidence-only correction.
- Run schema 1.5 bound clean source commit
  `97e3d8ec65a87d8339e11afe5cdcd17731521308`, the exact context manifest,
  source inputs, fixture trees, command vectors, logs, Python 3.13.0, Darwin
  arm64, and the Codex runtime executable.

## Diagnostic correction

An initial 1.0.3 diagnostic run showed valid Knowledge IDs but zero required
Knowledge coverage and poor decision accuracy. The full Solution Advisor
treatment supplied only foundation entries, so the model could not use the
styles, decision guides, or case studies declared by the Ground Truth. Commit
`97e3d8ec65a87d8339e11afe5cdcd17731521308` repaired the treatment with the
workflow-relevant knowledge union and added a regression test requiring every
declared required Knowledge ID to be present. The release-candidate runs above
were executed from that clean commit; the diagnostic runs are not release
evidence.

## Interpretation and limitations

Both models avoided every fixture-specific forbidden recommendation, selected
no over-designed target, cited only valid Knowledge IDs, and produced complete
rejected-option explanations and reversible migration slices. The context fix
restored correct decisions across the queue-worker, server-first mobile,
modular-monolith, and single-agent cases.

Measured limitations remain. Sol emitted six false-positive Finding instances;
Terra emitted two. Both missed some expected Findings and severity varied,
especially in stateful and shared-data cases. Required Knowledge coverage was
not perfect, and Terra's severity agreement was 0.735.

The adversarial corpus exercises four focused public Skills:
`project-architecture-audit`, `ai-agent-architecture-audit`,
`architecture-finding-verifier`, and `architecture-solution-advisor`. The dated
Codex host report separately exercises the `hengmu` router. This report does
not provide model behavior evidence for `mobile-architecture-audit`,
`portfolio-architecture-audit`, `architecture-remediation-planner`, or
`architecture-quality-gate`; their direct, indirect, incomplete, negative, and
edge contracts remain statically covered by `evals/cases.yaml`. No universal or
future-model behavior claim is made.
