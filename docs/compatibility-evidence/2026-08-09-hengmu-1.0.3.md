on the named host and does not imply equivalent activation in another client or
future client version.

avoid a same-name routing collision, then restored after the 1.0.3 smoke. The
temporary 1.0.3 plugin and marketplace were removed after the observation.

## Portable package and unavailable hosts

`9adf1e309e2cae64e32e63f54bae72bc18a9ed43b8b432ab6b58a606253ce935`
and passed the repository's extracted Knowledge Selection smoke test. This is
package evidence, not installed-host evidence.

Cursor, VS Code, GitHub Copilot CLI, and Kiro executables or applications were
not available on this machine, so no Hengmu 1.0.3 activation claim is made for
those hosts. ChatGPT desktop 26.803.41515 was installed, but this run did not
install or route Hengmu through its graphical plugin surface; that outcome
remains unverified.

## Reproduction boundary

The native observation used a local marketplace containing the exact built ZIP
and then ran Codex in a read-only task. Repository CI separately verifies both
archives' deterministic contents, extracted Knowledge Selection path,
checksums, and SPDX SBOM generation. A future host or Hengmu package-contract
change requires a new dated report rather than reusing this one.
